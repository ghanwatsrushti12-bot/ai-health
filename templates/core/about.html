About {{ SITE_NAME }}

{{ SITE_NAME }} is a modular hospital front-desk platform built to demonstrate a production-grade Django architecture: role-based dashboards, a real-time appointment scheduler, an explainable symptom triage tool, ambulance dispatch tracking, and staff analytics — all in one modern interface.

This project is organised as a set of focused Django apps (accounts, doctors, appointments, triage, ambulance, feedback, dashboard, core) that each own a single responsibility, communicate through well-defined foreign keys, and can be extended independently.

Modular by design

Every domain is its own Django app with its own models, forms, and templates.

Role-aware access

Patients, doctors, and staff each get a tailored dashboard and permission set.

Deployment ready

Gunicorn, WhiteNoise, and environment-driven settings out of the box.
